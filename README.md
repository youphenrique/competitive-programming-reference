# Competitive Programming Reference

A collection of standalone implementations of algorithms and data structures commonly used in programming contests. Most examples are written in C++, with selected implementations also available in Kotlin.

The collection includes graph algorithms, data structures, string processing, number theory, sorting, searching, and other common contest techniques.

## Using the examples

Each source file focuses on a single topic and can be read or adapted independently. Many files include their own `main` function and demonstrate input and output. Check the comments and code for assumptions such as input format, indexing, graph direction, and constraints, then adapt them to the problem you are solving.

Compile or run an individual file with the appropriate compiler or runtime for its language. The repository is a reference collection rather than a single integrated application.
